# MY REACT MINI PROJECTS

Here are the list of all the Project I made:
1. Accordion -> Where the div can click and show the content.
2. Random Color -> Click the button and i will give you a random hex color.
3. Star Rating -> When you click the star it will say how many star do you rate.\
4. Load more -> where I use API to use Loadmore function.
5. Recursive menu -> mostly use in sidebar, where when you click the button it will show below another menu.
6. QR Generator -> Enter a text and press the button to generate the QR Code.
7. Switch Dark and Light -> switching dark/light theme.
8. Custom Scroll Indicator -> while scrolling the bar indicate where you scroll.
9. Tabs -> Like accordion but this 1 is like a menu with the content below.
10. Modal -> click the button and the modal show the content.
11. Github Profile Finder -> I used the Github API for this project, where you can find who are you looking for.
12. Search Autocomplete -> I used another API here where you can search different user when you type in textbox.
13. Tic Tac Toe -> I like tic tac toe, though this project is common, I want to try how this game made in React.
14. Custom Hooks -> I try to build a custom hook also. if you click the green menu, it will show you the custom hooks.
